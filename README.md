# 个人工具中心

Windows 本地桌面工具集合，包含游戏管家、快速文件打包、小镇与专注、图标换装台及可选桌面状态卡片。保留当前新版页面和布局；旧版中心、独立旧游戏/论文窗口不再作为入口分发。

## 安装与启动

1. 安装 Python 3.11 或 3.12（含 Tk、Python Launcher）及 Microsoft Edge WebView2 Runtime。
2. 运行 `setup.cmd` 创建本包 `.venv` 并安装依赖。
3. 运行 `check.cmd` 检查源码、依赖与前端；再运行 `start.cmd`。

也可自行 `python -m pip install -r requirements.txt`，然后运行 `python -B "tools/个人工具中心新版/app.py"`；追加 `--check` 可进行不启动 GUI、不扫描桌面、不打开外部程序的只读检查。

正常运行不需要 Node.js，两个生产前端已附带。请解压在自己可写的目录，并保持 `tools/` 内部结构。

## 功能与边界

| 功能 | 使用方式 |
|---|---|
| 游戏管家 | 新版内页管理游戏中文/英文名、别名、收藏、修改器和存档目录；初始游戏库为空；手动导入本机 Steam 游戏或添加条目 |
| 快速打包 | 新版内页选取文件和输出目录，生成 ZIP，查看进度，再次打包 |
| 小镇与专注 | 独立统一窗口，布置、互动、计时；初始进度全新，没有角色图片时使用占位 |
| 图标换装 | 自带有权使用的 ICO，读取桌面普通软件快捷方式；预览后应用，支持还原；不会替换文件夹内快捷方式 |
| 桌面状态卡片 | 附 C++/Win32 源码，自行编译；未编译时入口提示不可用 |
| Agent 工作台 / 桌宠 | 可选独立应用，不随本包附带；未配置时不启动任何私有服务 |

状态卡片需 Visual Studio C++ Build Tools 与 Windows SDK，在其开发者命令行运行 `tools/桌面状态卡片/build.cmd`；会先执行计数逻辑测试，再编译程序。Ctrl+Alt+F9 由其托盘启动器注册，本次源码包不附带 EXE。

## 可选集成

Agent 工作台另有独立源码包。将 `agent-workbench` 与本目录 `personal-tool-center` 并排放置，或设置 `AGENT_WORKBENCH_ENTRY` 指向自己的工作台 `app.py`。启动使用中心的 Python，因此需先安装中心 requirements。工作台缺失不影响其他功能。

桌宠通过界面的桌宠按钮设置自己的 `.lnk/.exe` 入口（右键可重新选择），或检测当前用户桌面的 `Agent 桌宠.lnk`。本包不含桌宠、角色图片或其账号/服务配置。

## 素材与资料隔离

不附带宝可梦图片、图标合集、游戏库、存档、修改器、论文文件、真实材料路径、近期记录、图标还原备份、API 密钥或作者环境。

图标换装可在界面选择 ICO 文件夹，或将自有素材放入 `tools/个人工具中心/assets/pokemon/`。小镇自有素材可放入 `tools/宝可梦小镇新版/assets/pokemon/`，按 `town_state.py` 的 ID 命名。名称是兼容源码的约定，不授予品牌或素材使用权。

运行数据存于各工具相邻的 `data/`，日志在 `logs/`，用户选择的文件不复制到源码。所有 data/logs、素材目录、缓存、导出 ZIP、EXE 和本机设置已在 `.gitignore` 排除。不要把运行后的整个目录直接重新压缩公开，应重新按源码白名单打包。

图标生效依赖 `tools/个人工具中心/data/icon_studio/assets/` 中持久 ICO；还原记录和备份也在该 data 中。修改过快捷方式后，请先还原再移动/删除这些文件，避免桌面图标失效。这个包不会读取原安装的图标记录，也不会还原原安装做过的修改。

## 开发

Node.js 22.8+（含 npm），运行 `build-frontend.cmd` 即可独立安装和重建中心、小镇前端。各自 frontend 中可运行 `npm test`。Python 测试位于各工具的 `tests/`，使用临时资料与模拟动作；需要原生 Tk/COM 的测试另有依赖或明确的启用开关。
