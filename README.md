# 个人工具中心 · 可迁移模板

Windows 本地工具集合。包含 React + pywebview 新版中心与相邻工具的可读源码，空资料库启动；运行所需的两个前端 `dist` 已一并构建。无需 Codex，也不依赖作者账号、工作目录或 Python 缓存。请解压到普通用户可写的目录，并保持 `tools` 下中文目录名和相邻关系。

## 包含什么

| 入口 | 包内实现与边界 |
|---|---|
| 新版工具中心 | 搜索、分类、主题与字号、最近使用、工具启动与窗口唤起、白名单本地接口 |
| 游戏管家 | 空游戏资料库、中文名/英文名/别名、收藏、备注、自选修改器路径、Steam 本机库读取、存档备份与导出；不包含游戏或修改器 |
| 快速打包 / 论文交付助手 | 手选文件 ZIP、再次打包、材料校验、交付记录；不包含任何实际论文、PPT、图表或历史交付包 |
| 资料入口 | 用户自行选择论文、演示文件、图表目录，再打开或打包 |
| 游戏转盘 | 手动候选、从用户本机 Steam 导入、排除最近项目、挑战提示；初始候选为空 |
| 小镇与专注 | 家具摆放、伙伴互动、每日奖励、专注计时与本地进度；不附带角色图片，无素材时显示文字占位 |
| 旧版中心 / 专注小屋 | 保留 Tk 界面与核心逻辑，便于独立使用 |
| 图标换装台 | 用户自行提供 ICO；预览、修改普通桌面快捷方式、备份与还原。素材缓存及还原记录均写入包内对应工具的 data |
| 桌面状态卡片 | C++17 / Win32 源码、性能计数测试、构建脚本；需自行编译后才能从中心启动 |

## 安装与启动

1. 准备 Windows 10/11、Python 3.11 或 3.12（安装 Tk 和 Python Launcher）、Microsoft Edge WebView2 Runtime。Python 版本需满足固定的 pythonnet / pywebview 依赖。
2. 在解压目录运行 `setup.cmd`。脚本通过 Python Launcher 优先选择 Python 3.12，找不到时选择 3.11，创建本目录 `.venv`，再通过 pip 安装 `requirements.txt`；二者均未安装时提示安装并退出。此步骤需要可访问 Python 包源。
3. 双击 `start.cmd`。使用本目录 `.venv`；尚未安装时会提示先运行 `setup.cmd`。发生启动错误会保留控制台信息。

已有合适 Python 环境也可执行：

```powershell
python -m pip install -r requirements.txt
python "tools/个人工具中心新版/app.py"
```

正常运行不需要 Node.js。第一次运行会自行生成各工具的 `data`、日志及 WebView 浏览器资料。所有本地保存都在工具相邻目录；请避免解压到只读目录。更换目录前先关闭全部工具；已选择的个人文件路径与已经修改的快捷方式图标路径不会自动迁移。

## 修改和构建前端

安装带 npm 的 Node.js 22.8+，运行根目录 `build-frontend.cmd`，依次对中心与小镇执行 `npm ci` 和 `npm run build`。也可分别进入两个 `frontend` 目录执行这些命令。两处均包含源码、脚本、锁文件和构建产物，不包含 `node_modules`。另保留原 `pnpm-lock.yaml` 及对应配置，供使用 pnpm 的开发者参考。

```powershell
npm ci
npm test
npm run build
```

## 可选：桌面状态卡片

安装 Visual Studio C++ Build Tools 与 Windows SDK，打开 **x64 Native Tools Command Prompt**，运行 `tools\桌面状态卡片\build.cmd`。脚本先运行计数逻辑测试，再生成同目录的 `DesktopStatusCard.exe` 和 `HotkeyLauncher.exe`。之后工具中心对应入口才能使用。没有编译时，点击入口会提示文件缺失。

Ctrl+Alt+F9 由快捷键启动器注册；退出托盘启动器后停止响应。不设置开机启动。模板移除了原有角色图标资源，保留系统默认图标。没有在本次打包环境重新编译或启动这一工具。

## 素材和配置由使用者提供

- 图标换装：可在界面选择持有使用权的 ICO 目录；也可放入 `tools/个人工具中心/assets/pokemon`。此目录名是旧实现的兼容约定，不代表附送任何品牌素材。
- 小镇：可将有权使用的透明 PNG 放入 `tools/宝可梦小镇新版/assets/pokemon`，文件名需匹配 `town_state.py` 中的伙伴 ID；未提供时使用文字占位。角色名称沿用源码的标识，角色图片和品牌授权均未包含。可自行修改目录名、ID 和展示文案，但需同步修改校验规则。
- 桌面换装会真实修改用户选择的快捷方式，并在操作前保存还原资料。保留 `data/icon_studio` 以便还原；移动或删除正在被快捷方式引用的素材缓存会影响图标显示。
- `examples` 是新建的空配置示例，不是作者的配置。默认不需复制：程序在缺少配置时使用等效空值。按示例旁的目录说明放置后也可工作。
- Steam 仅读取使用者机器的标准位置或注册表。程序包含 `steam://` 启动支持，需用户已安装 Steam。导入、添加或启动游戏、修改器均由用户操作触发。

## 排除内容

未收录实际游戏库、游戏存档、修改器 EXE、Steam 缓存、用户材料、桌面快捷方式映射、图标还原备份、旧配置、浏览器缓存、历史 ZIP、日志、作者账号或绝对路径。未收录宝可梦图片、桌面角色图标、模型权重、第三方二进制与 Python/Node 运行环境。没有包含独立的“论文工作台”、桌面宠物或它们的私有服务；这些不是当前中心桥接运行所需代码。

## 验证及限制

已对这份模板重新构建两个生产前端，并通过前端单元测试；Python 核心测试覆盖桥接白名单、游戏资料冲突保护、材料、打包、备份、快捷方式服务、专注、转盘、小镇状态等。移动到另一目录的副本可完成 bootstrap，初始游戏、资料路径、最近使用为空，工具路径全部位于副本内；状态卡片二进制作为明确的可选项除外。

npm 锁文件由原 pnpm 锁定版本/完整性和已安装包元数据整理生成；随后在两个隔离副本、独立缓存中，从官方 npm registry 实际通过 `npm ci --ignore-scripts --no-audit --no-fund`、`npm run build`、`npm test`。重新构建不依赖原目录的 node_modules。日常运行仍只需要已附带的 dist 与 Python 环境。

本次未启动真实 GUI、修改桌面快捷方式或启动外部程序。完整 WebView2 / Tk UI、不同 Windows 账号、系统权限、Windows 单实例握手和 Python 依赖安装仍需使用者在目标系统验证；沙箱中的单实例握手测试未通过，不能视为已验证。第三方 Python 依赖需要安装；边界接口测试使用了相同版本的本机已有依赖，不代表模板内捆绑它们。
